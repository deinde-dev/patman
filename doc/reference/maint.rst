patman maint
============

Apply series from the list as a maintainer, then check and test the commits
which you are about to push, run CI on them, publish them, thank their
submitters and finish with each series, by the project's rules in the ``[maint]`` section of the settings
(see :doc:`/maint`).

.. patman-command:: maint
